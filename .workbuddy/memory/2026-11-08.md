## 架构决策（2026-11-16 定案）：词鹿后台 = 新建统一管理后台 admin_platform

- 用户明确：tooldeer_com 和 toolBatch.com 已上线，**不合并进来**；产品间无强关联；
  **每个产品独立 MySQL 业务库**（不统一用户表/会员表）——"一套系统多库"。
- 落地：新建 `D:\phpstudy_pro\WWW\go\admin_platform`（beego v2.2.0 + gorm v1.30.1，独立 git 仓库）。
  结构：`platform_meta` 元数据库（app 注册表/admin_user/admin_app_role/audit_log/stat_daily，全局唯一）
  + 每产品一库（词鹿 = `app_worddeer`，表：account/account_profile/word/word_cefr/word_topic/
  content_version/learning_progress/curriculum_progress/pay_order）。库即租户，业务表无 app_id 列。
- 核心机制：`internal/platform/tenant` 按产品代号路由独立连接池（每库 MaxOpenConns=10），
  **代码里无包级全局 DB**，controller 基类 base.Controller 在 Prepare 按 session 选库放 c.DB。
- 已完成并验证：登录（bcrypt，首次启动自动建 admin/admin123）、产品切换、概览看板、
  词库管理（搜索/筛选/编辑/上下架/批量导入/发布内容包）、App 接口
  `GET /api/v1/{code}/content/latest`（带本地 version 返回 up_to_date）。
  词库已导入 7201 词，内容包 v1 已发布（static/content/wordbank_v1.json，845KB）。
- 踩坑记录：
  1. **内容包 md5 不能写进文件**：md5 必须对"整个文件字节"算，客户端下载后直接 md5 文件比对；
     塞进文件里服务端/客户端永远对不上。且 Go json.Marshal 默认转义 <>& 为 \u003c 等，
     必须 `enc.SetEscapeHTML(false)`。
  2. `c.Ctx.Input.Host()` 会丢端口，拼完整下载 URL 要用 `c.Ctx.Request.Host`。
  3. beego v2 file session provider 在 `session` 包内自动注册（sess_file.go），无需额外 import
     `session/file`（该子包不存在，v2.3 才拆分）。
- 词库数据源：`app_worddeer/assets/words.json` 是紧凑数组 `[en,zh,detail,us,uk,sort,cefr,"主题1,主题2"]`
  共 7201 条（A1 825/A2 1057/B1 1995/B2 2266/C1 692，60 主题），导入工具 `cmd/importwords`。
- 后续待做：账号（Apple 登录+手机号）、进度同步（App 本地优先，按 client_updated_at 合并）、
  订阅（AS Server API v2，pay_order.original_transaction_id 关联续期）、发音接口迁移。

游戏界面 · 三方案对比

同一套玩法（5 对 5、错词隔 2~3 次重现、配对即补位），三种界面语言。每个预览都能直接点着玩：先点英文卡，再点对应中文卡。

A卡片桌经典款
打开全屏 ↗
  • ·左右分栏固定：左英文 + 音标，右中文 + 词性
  • ·配对成功先蹦一下，再炸成纸屑 + 卡片碎片
  • ·配错是上下颠，不左右晃，视线不离开列
★ 已选定。适合 成人 / 正式学习场景，与 demo.html 同构，移植成本最低。
B连线极简款
打开全屏 ↗
  • ·两列留出中间通道，配对时画出贝塞尔连线
  • ·选中一侧会出现指向中缝的虚线牵引
  • ·白底留白，安静、专注，文字信息密度高
适合 偏工具型 / 高年级用户，最能体现“词与义之间的连接”这件事。
C消消乐混排游戏款
打开全屏 ↗
  • ·10 张卡打乱混排，英中不分列，寻找难度更高
  • ·配对成功爆粒子 + 飘字，新卡从上方掉入
  • ·深紫底 + 金色连击，情绪浓度最高
适合 青少年 / 追求留存与爽感，但混排会牺牲一点“扫读效率”。
三个都实现的部分

5 对 5 同屏、点两张判定、配对成功补位、配错后延迟 2 次重现（直到配对正确）、连击计数、计时、顶部进度（x / 20，正式每关 50）、结算页（正确数 / 一次选对率 / 最高连击 / 错词回顾）。深链 #mid 看进行中、#done 看结算，方便截图评审。
